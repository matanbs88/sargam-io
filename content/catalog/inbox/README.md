# Score corpus inbox

Place one source score per catalog item here during local batch preparation.
Preferred formats, in order:

1. MusicXML/MXL;
2. MIDI;
3. clear staff-notation PDF or image for the configured OMR adapter.

Keep the filename aligned with the catalog ID, for example:
`let-it-be.musicxml` or `tum-hi-ho.pdf`.

The inbox is intentionally not imported automatically. Each batch must be
parsed, validated, reviewed, and attached to the catalog through the score
corpus workflow before it becomes playable.
