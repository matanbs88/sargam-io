# Partnerships and vendor correspondence

This folder stores durable copies of partnership inquiries, vendor replies,
licensing discussions, and integration decisions that affect Sargam.io.

## Filing rules

- Save the exact approved message before sending it through a vendor website,
  email, or contact form.
- Save the vendor's reply verbatim when received, together with the date and
  the channel used.
- Keep URLs, product claims, pricing, and licensing assumptions in the
  document so the discussion can be audited without searching chat history.
- Do not place secrets, API keys, personal access tokens, or private customer
  data in this folder.
