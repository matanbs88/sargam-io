# Ventus Bansuri web licensing inquiry

**Status:** Founder-approved prototype integration — commercial release deferred
**Channel:** Vendor website contact form
**Prepared:** 2026-08-28
**Recipient:** Impact Soundworks / Ventus Winds

This is the final short version approved for submission through the vendor's
website. It intentionally contains no product URL or website address.

## Message

```text
Subject: Web Licensing Inquiry — Ventus Bansuri

Hello Impact Soundworks team,

I am building an early-stage browser-based Indian music practice application focused on Sargam notation and guided melody practice.

We are interested in using Ventus Winds Bansuri as the guided instrument sound. Users would trigger pitch-mapped notes during practice, but would not be able to download or access the original samples.

The product is currently a non-monetized prototype. We would like to understand the licensing requirements for future browser-based commercial use.

Do you offer a Web, OEM, SDK, or custom license that permits:

- Browser-based interactive playback
- Pitch-mapped note playback
- Secure streaming or temporary caching
- Use in user practice sessions
- Future commercial subscriptions

Please send us the relevant terms and pricing.

Best regards,
Matan
```

## Vendor reply

Received from **ISW Partners**:

```text
Hi Matan,

Sounds like an interesting project! Our typical user license does not cover this kind of usage, but we could allow this usage with a custom license of $500 once the commercial product is ready for release. Until then, you could use it for prototyping without the custom licensing.

--
ISW Partners
```

## Product interpretation

- **Allowed now:** Use Ventus Bansuri for local and non-commercial prototyping.
- **Before commercial release:** Obtain the custom license quoted at **$500**.
- **Not yet confirmed:** Exact scope of browser delivery, streaming/caching,
  redistribution restrictions, attribution, seat/user limits, and whether the
  quoted price is one-time or recurring.
- **Implementation decision:** Integrate Ventus as the approved prototype
  Bansuri asset. Commercial-release configuration is deferred and must not
  block MVP engineering.
