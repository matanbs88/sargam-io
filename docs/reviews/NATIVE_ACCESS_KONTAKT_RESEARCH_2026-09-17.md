# Native Access / Ventus playback setup

Local recheck after founder installation: Native Access.exe now exists at
C:/Program Files/Native Instruments/Native Access/Native Access.exe.
NTKDaemon 1.32.0.0 is registered. Kontakt itself was not found in the checked
Native Instruments application and Common Files/VST3 locations. Account
entitlements were not inspected; no claim that the founder lacks a full license.

Verified official sources:
- https://support.native-instruments.com/support/solutions/articles/69000879762-how-to-use-ni-sample-libraries
  Native Access installs Kontakt Player or full Kontakt.
- https://impactsoundworks.com/product/ventus-winds-bansuri/
  Ventus Bansuri requires Kontakt 5.5.2+ Full; not a Player-compatible library.
- https://www.native-instruments.com/products/kontakt-player
  Non-Player instruments can be tried for 15 minutes in demo mode, no saving.
  Kontakt supports standalone use; buying/installing a DAW is unnecessary.
- https://support.native-instruments.com/support/solutions/articles/69000879721-setting-up-a-third-party-kontakt-library
  Non-Player libraries are loaded manually from files, not registered with a
  Native Access serial. Ventus download code belongs to Pulse.

Recommended no-purchase diagnostic path: use Native Access to install available
Kontakt, launch standalone, load local Instruments/Bansuri.nki. If account has no
full Kontakt entitlement, use the official limited demo for a short audition;
actual successful patch loading still needs verification. Do not assume unlimited
use or offline export is available in demo. Full Kontakt only becomes a purchase
decision if sustained work with the vendor instrument is needed.

This is a local reference instrument, not a browser SDK/API. Installing it does
not automatically add its legato/dynamics/ornaments to the web sampler.
No purchase, license activation or account action performed in this research.
